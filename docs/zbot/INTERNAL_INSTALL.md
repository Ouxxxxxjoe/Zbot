# 内部安装说明（未签名包）

内部测试包**没有** Windows / macOS 代码签名。系统会拦一次，按下面做就能打开。  
**这不是安装包损坏。**

当前只发两个包：

| 系统 | 文件 | 架构 |
|---|---|---|
| Windows | `zagent-<版本>-Setup.exe` | 64 位 Intel/AMD（x64） |
| macOS | `zagent-<版本>-arm64.dmg` | Apple 芯片（M 系列） |

打开后直接进本机工作区，**不用登录、没有云服务**。模型用你自己的 Claude Code / Codex / API key，或本机 Ollama。

---

## Windows

1. 双击 `zagent-*-Setup.exe`。
2. 若出现蓝窗 **「Windows 已保护你的电脑」**：
   1. 点 **更多信息**
   2. 点 **仍要运行**
3. 按安装向导完成。开始菜单里打开 **Zbot**。

以后再开一般不会再拦。若 SmartScreen 反复出现，把安装包放到本机磁盘后再装（不要直接从网盘/压缩包里双击）。

不支持：Windows ARM、32 位。

---

## macOS

1. 打开 `zagent-*-arm64.dmg`，把应用拖进 **应用程序**。
2. **第一次打开**不要双击。在启动台或应用程序里：
   - **按住 Control 点图标**（或右键）→ **打开** → 再点 **打开**
3. 若仍提示「无法验证开发者」：
   1. **系统设置** → **隐私与安全性**
   2. 拉到下面，点 **仍要打开**
4. 还不行时，终端执行后再从应用程序打开：

```bash
xattr -cr /Applications/Zbot.app
```

应用名以安装后为准；若拖进去的名字不是 `Zbot.app`，把路径换成实际名字。

不支持：Intel Mac（本内部包只打 Apple 芯片）。系统低于当前 Electron 要求时也无法运行。

---

## 打开之后

- 应直接进入主界面，**没有登录页**。
- 侧栏账号显示为未登录，这是本地模式，正常。
- 没有「下载手机端」，也没有自动更新。换版本：再装一份新安装包。

装不上、或打开后白屏：把安装包文件名、系统版本、上面卡在哪一步发给打包的人。
